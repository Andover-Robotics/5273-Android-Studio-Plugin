# Installation

## Prerequisites
You should be using Android Studio Ladybug 2024.2 or later, and have the plugin zip file downloaded from [the releases page](https://github.com/Andover-Robotics/5273-Android-Studio-Plugin/releases).

## Instructions
1. Open Android Studio.
2. At the top of the IDE, click on File -> Settings.
3. Click on Plugins, then the settings icon. Click on Install Plugin from Disk...
4. Locate the plugin zip file and click OK.
5. Click on the green Restart IDE button.
6. Profit!
